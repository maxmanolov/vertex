VERTEX BENCHMARK FOR WINDOWS

Before you start

1. Install Minecraft Java Edition 1.7.10.
2. Start version 1.7.10 one time, and then close the game and its launcher.
3. Extract all files from this ZIP to one folder.

Run the benchmark

1. Select one or more supported Minecraft 1.7.10 client JAR files.
2. Drag the files onto benchmark.cmd. You can also start benchmark.cmd and use
   the file window.
3. Do not use the computer during the test.
4. Read summary.html when the test is complete.

The test covers a fixed scene, chunk travel at 24 blocks per second, 1,920
block and lighting updates per second, and 160 moving pigs. The standard test
runs three repetitions for each client.

Use client JAR files from a source that you trust. The file check identifies a
supported client structure. It is not a security scan.

Results and disposable game files are under %LOCALAPPDATA%\VertexBenchmark.

The tool prints the result folder. Keep all files in that folder if you share a result.
Do not compare results from different computers.
